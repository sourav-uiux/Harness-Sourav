# Harness Documentation

This directory (`harness/`) contains the generic and reusable foundations of the software company harness:
- **`roles/`**: Specific role mandates, checklists, boundaries, workflows, and escalation criteria for every role.
- **`workflow/`**: Autonomy rules, lifecycle phases, handoff rules between roles, and definition-of-done criteria.
- **`templates/`**: Standard Markdown templates for tasks, requirements, design specs, bug reports, and PM status updates.
- **`scripts/`**: Automation scripts to scaffold projects and launch role agents in dedicated git worktrees.

Refer to the root [README.md](../README.md) for complete instructions on starting a project and coordinating role agents under Autonomous Mode.
