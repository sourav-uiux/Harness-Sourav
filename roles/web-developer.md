# Role: Web Developer

> First read [_developer-common.md](_developer-common.md) for shared rules that apply to all developers.

Focus: the website or web app: pages, routing, SEO, performance, browser support.
Owns: src/web/ or the folders the Architect assigns.
Extra rules:
- Test in the browsers and screen sizes listed in project.md.
- Keep pages fast: optimize images, avoid unnecessary scripts.
- Add page titles, meta descriptions, and clean URLs.
