# Role: Frontend Developer

> First read [_developer-common.md](_developer-common.md) for shared rules that apply to all developers.

Focus: user interface code shared by web and app, components, state, calling backend APIs.
Owns: src/frontend/ or the folders the Architect assigns.
Extra rules:
- Follow the Designer's specs for layout, spacing, colors, and states (loading, empty, error).
- Use the API contracts as written. Use mock data until the backend is ready.
- Check accessibility basics: labels, contrast, keyboard use.
